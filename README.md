# ChurnPredict

Sistema web de Machine Learning para la predicción del riesgo de abandono de clientes.

## Descripción

ChurnPredict es una aplicación web desarrollada con Python y Flask que utiliza técnicas de Machine Learning para analizar información histórica de clientes y estimar su riesgo de abandono.

## Tecnologías

- Python
- Flask
- Pandas
- NumPy
- Scikit-learn
- HTML
- CSS
- JavaScript
- Bootstrap
- Chart.js
- SQLite
